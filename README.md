# 커뮤니케이션2국 모니터링

5대그룹·대기업 뉴스, 연합뉴스 실시간 인사·부고, 영업 기회와 부정이슈, 광고·협찬 동향을 한 화면에 모아 보는 사이트입니다.
**모두 무료 서비스로만 돌아가며**, PC를 꺼 두어도 정해진 시간에 자동으로 업데이트됩니다.

- **사이트 주소: https://combon.vercel.app** (예전 GitHub Pages 주소는 사용 중지)
- 구조: GitHub Actions가 정해진 시간에 수집 → 결과를 이 저장소에 저장 → Vercel(프로젝트 `combon`)이 저장을 감지해 자동 재배포
- Vercel 설정은 `vercel.json`(빌드: `node build.js`, 결과 폴더: `_site`)에 들어 있어 Vercel 화면에서 따로 바꿀 것이 없습니다.

## 브리핑 구성 (매일 오전 9시 자동 작성)

1. **주요영업처 소식**: `config.js`에서 주요영업처(`W(...)`)로 지정한 곳 중 새 기사가 있는 곳은 **한 곳도 빠짐없이** 표시. 부정이슈 → 인사 → 영업 기회 → 일반 동향 순
   - 평소엔 최근 26시간, **월요일엔 주말 포함 72시간** 기사를 봅니다
2. 인사 체크: 홍보·커뮤니케이션 라인 인사 전부 + 주요영업처 인사 전부
3. 부정이슈: 주요영업처는 전부, 그 외 기업은 상위 몇 건
4. 오늘의 제안 포인트: 주요영업처 우선
5. 경조사 체크: 주요영업처·홍보 담당자 부고 전부
6. 광고·협찬 동향: 주요영업처 언급 우선

## 자동 업데이트 시간 (한국시간, 매일)

| 시간 | 하는 일 |
|---|---|
| 09:00 | 전체 수집 + 브리핑 새로 작성 |
| 10:00 | 인사·부고만 수집 |
| 16:00 | 인사·부고 포함 전체 수집 (브리핑은 오전 것 유지) |
| 16:45 | 인사·부고만 수집 → 오후 단체 메시지 확정 (17:00~17:30 발송용) |

GitHub 사정에 따라 몇 분~30분 정도 늦게 실행될 수 있습니다.

## 파일 구성

| 파일 | 내용 | 직접 고칠 일 |
|---|---|---|
| `config.js` | 관심 기업 목록, 기회·부정이슈 키워드, 협찬 동향 검색어 | **자주** |
| `collect.js` | 연합뉴스·구글 뉴스에서 자료를 모으는 수집기 | 사이트 구조가 바뀌었을 때만 |
| `briefing.js` | 브리핑 자동 작성 규칙 | 가끔 (할 일 문구 등) |
| `index.html` | 사이트 화면 | 화면을 바꿀 때 |
| `build.js` | 사이트 파일 만드는 스크립트 | 고칠 일 없음 |
| `.github/workflows/update.yml` | 자동 실행 시간표 | 시간을 바꿀 때 |
| `data.json`, `briefing.json` | 수집 결과 (자동으로 바뀜) | 고치지 않음 |

## 처음 설정하기 (한 번만)

1. **GitHub 가입**: https://github.com 에서 무료 계정을 만듭니다.
2. **저장소 만들기**: 오른쪽 위 `+` → `New repository`
   - 이름 예: `sponsor-desk`
   - **Public** 선택 (공개 저장소여야 자동 실행이 무제한 무료입니다)
   - `Create repository`
3. **파일 올리기**: 새 저장소 화면에서 `uploading an existing file` 링크를 누르고, 이 폴더 안의 파일을 **전부** 끌어다 놓은 뒤 `Commit changes`.
   - `.github` 폴더도 꼭 포함해야 합니다. 숨김 폴더라 탐색기에서 안 보이면 `보기 → 숨긴 항목`을 켜세요.
   - `_site` 폴더는 올리지 않아도 됩니다.
4. **Vercel 연결**: https://vercel.com/new → GitHub로 로그인 → 이 저장소 `Import` → Project Name 입력(현재 `combon`) → `Deploy`.
   - 다른 설정은 건드리지 않습니다. `vercel.json`이 알아서 설정합니다.
5. **첫 실행**: 저장소 `Actions` 탭 → 왼쪽 `자동 업데이트` → 오른쪽 `Run workflow` → `brief` 선택 → 실행.
   - 1~2분 뒤 초록색 체크가 뜨면 완료. 수집 결과가 저장되면 Vercel이 자동으로 다시 배포합니다.
6. **사이트 주소**: `https://<프로젝트 이름>.vercel.app` (현재 https://combon.vercel.app)
   - 이 주소를 팀과 다른 부서에 공유하면 됩니다. 검색엔진에는 노출되지 않도록 설정되어 있습니다.

## 자주 하는 일

### 관심 기업 추가·삭제
1. GitHub 저장소에서 `config.js` 클릭 → 오른쪽 위 연필(✏️) 버튼
2. `companies` 목록에 한 줄 추가. **주요영업처는 `W(...)`로 적으면 소식이 있을 때 브리핑에 무조건 들어갑니다.** 예:
   ```js
   W("하이브", "엔터", "하이브 OR 빅히트뮤직", ["하이브", "빅히트"]),
   W("토스", "금융", "토스증권 OR 비바리퍼블리카", ["토스"], { exclude: ["토스트"] }),
   ```
   - 주요영업처가 아닌 참고용은 `{ name: ..., group: ..., q: ..., match: [...] }` 형태로 적습니다 (브리핑 필수 포함 X)
   - `name`: 화면에 보일 이름
   - `group`: 왼쪽 목록에서 묶일 분류 (5대그룹, 대기업, 금융, IT·플랫폼, 소비재 등. 새 이름을 쓰면 새 분류가 생깁니다)
   - `q`: 구글 뉴스 검색어 (`OR`로 여러 개)
   - `match`: 기사 제목에서 이 기업을 알아보는 단어. **제목에 이 단어가 없는 기사는 버립니다** (구글이 비슷한 이름의 다른 기사를 섞어 주는 것 방지)
   - `exclude` (선택): 제목에 있으면 이 기업으로 보지 않을 단어. 예: 토스 → '토스트', KT → 'KT&G'
   - 검색어 중 한 단어짜리는 자동으로 "정확히 일치" 검색이 됩니다
3. `Commit changes` → 다음 예약 시간부터 반영. 바로 보려면 `Actions` → `Run workflow`.

### 부정이슈·기회 키워드 바꾸기
`config.js`의 `signals` 부분을 고칩니다.
- `caution`: 부정이슈로 잡을 단어
- `cautionExcept`: 부정 단어가 들어 있지만 부정 뜻이 아닌 말 (예: '문화재단'의 '화재', '삼성화재')

### 업데이트 시간 바꾸기
`.github/workflows/update.yml`의 `cron` 줄을 고칩니다. **UTC 기준**이라 한국시간에서 9시간을 뺍니다.
- 한국 09:00 → `"0 0 * * *"`, 한국 16:00 → `"0 7 * * *"`
- 평일만: 끝의 `*`를 `1-5`로 (예: `"0 0 * * 1-5"`)
- 시간을 바꾸면 같은 파일 아래쪽 `실행 종류 정하기`의 cron 문자열도 똑같이 바꿔야 합니다.

### 지금 바로 업데이트
`Actions` → `자동 업데이트` → `Run workflow` → 종류 선택
- `brief`: 전체 + 브리핑 / `full`: 전체 / `people`: 인사·부고만

## 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 사이트 데이터가 안 바뀜 | `Actions` 탭에 빨간 X가 있는지 확인 → 눌러서 오류 메시지 확인 |
| 특정 항목만 비어 있음 | 해당 사이트가 수집을 막았거나 구조가 바뀐 경우. 수집이 실패하면 **직전 데이터를 유지**하므로 사이트가 비지는 않습니다 |
| 자동 실행이 멈춤 | 공개 저장소는 60일간 활동이 없으면 예약 실행이 꺼질 수 있습니다. GitHub이 메일로 알려주며, `Actions` 탭에서 `Enable workflow`를 누르면 다시 켜집니다 |
| 인사·부고가 0건 | 연합뉴스 사이트 구조 변경 가능성. `collect.js`의 `parseYnaList` 부분을 새 구조에 맞게 고쳐야 합니다 |

## 자료 출처와 이용 원칙
- 인사·부고: 연합뉴스 `people/personnel`, `people/obituary-notice` 목록
- 기업 뉴스·협찬 동향·그룹 임원인사: 구글 뉴스 검색(RSS)
- 사이트에는 **기사 제목과 링크만** 보여주고, 인사 기사는 홍보 관련 한 줄만 발췌합니다. 기사 전문은 원문 링크에서 확인합니다.
